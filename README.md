# Personal Homepage - Friederik Ferdinand

Repositori ini diperuntukkan untuk memenuhi Mid Project pada mata kuliah Pemrograman Web.

## 🚀 Fitur Utama

- **Desain Responsif**: Tampilan yang optimal di berbagai perangkat (desktop, tablet, dan mobile).
- **Galeri Portofolio**: Kumpulan proyek pengembangan web, trading crypto, dan dokumentasi perjalanan dengan fitur filter kategori.
- **Sistem Blog Dinamis**: Artikel blog dimuat secara dinamis menggunakan JSON, mencakup topik seputar Bitcoin, Web3, dan AI.
- **Formulir Kontak**: Integrasi dengan Formspree untuk pengiriman pesan langsung dari website.
- **Navigasi Interaktif**: Menu navigasi yang ramah pengguna dengan animasi scroll dan indikator halaman aktif.

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi web murni (*Vanilla*) tanpa library eksternal seperti jQuery atau Bootstrap:

- **HTML5**: Struktur konten semantik.
- **CSS3**: Styling kustom dengan CSS Variables, Grid, dan Flexbox.
- **JavaScript (ES6+)**: Logika filter galeri/blog, animasi reveal, dan pengambilan data artikel secara asinkron.
- **Google Fonts**: Tipografi menggunakan font 'Inter' dan 'DM Serif Display'.
- **Material Symbols**: Ikonografi yang bersih dan modern.

## 📁 Struktur Folder

- `index.html`: Halaman Utama.
- `about.html`: Halaman Profil.
- `gallery.html`: Halaman Portofolio.
- `blog.html`: Halaman List Blog.
- `article.html`: Halaman Detail Artikel.
- `contact.html`: Halaman Kontak.
- `assets/css/style.css`: Kode utama styling.
- `assets/js/script.js`: Logika frontend dan interaksi.
- `assets/data/articles.json`: Database konten artikel blog.
- `assets/`: Folder berisi ikon dan gambar pendukung.
